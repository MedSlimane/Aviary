# Aviary Texture Pack

Eight landscape raster textures for Aviary’s near-black macOS interface. Each asset is abstract, full-bleed, text-free, and designed to tolerate cropping across wide UI surfaces.

| File | Palette | Intended surface |
| --- | --- | --- |
| `tex-aurora.png` | Violet, periwinkle, pale blue, pearl white | Luminous card headers, hero banners, welcoming empty states, and modal tops |
| `tex-ember.png` | Peach, coral, amber, soft rose | Warm feature cards, onboarding moments, celebratory empty states, and modal tops |
| `tex-tidal.png` | Deep teal, seafoam, mineral blue-green, pale gold | Calm status cards, agent detail heroes, focused empty states, and modal tops |
| `tex-dusk.png` | Deep indigo, plum, magenta, muted rose | Dramatic feature headers, high-emphasis cards, and dark modal tops |
| `tex-pearl.png` | Warm white, dove grey, cool silver, faint spectral pastels | Restrained cards, quiet settings surfaces, neutral modal tops, and low-emphasis banners |
| `tex-obsidian.png` | Carbon black, blue-black, near-black violet, near-black teal | Full-bleed window backgrounds behind dense UI and other low-contrast dark surfaces |
| `tex-silk.png` | Warm neutral grey, pearl, pale peach, lilac, cool silver | Tactile card headers, premium hero banners, empty states, and modal tops |
| `tex-bloom-abstract.png` | Near-black, indigo, amber, rose, violet, cyan, pearl | Expressive empty states, atmospheric hero banners, and highlight cards |
